Normalisation (identical to the SQL views): form 10-K, fp FY, 350-380 day duration (instants: no start), `fiscal_year = YEAR(period_end - 45 days)`, one row per (ticker, concept, fiscal_year) choosing the latest period_end, then the best tag, then the latest filing.

Known gaps in the real data (not bugs): Walmart/GM report no GrossProfit; Kroger has no InventoryNet and sparse CostOfRevenue; Target reports NetIncomeLoss only from FY2020 under that tag; Ford OperatingIncomeLoss starts 2017. EDGAR content is filer-authored: query/cite, do not redistribute as a dataset.
